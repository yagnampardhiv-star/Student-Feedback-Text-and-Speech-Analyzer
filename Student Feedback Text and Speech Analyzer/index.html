ABOUT THE PROJECT

Turn Student Opinions Into Insights.

Student Feedback Text and Speech Analyzer is a web-based application designed to help educational institutions understand student opinions more efficiently.

The system accepts both written and spoken feedback, analyzes the content, detects sentiment, and extracts important keywords. This can help faculty and institutions identify strengths and areas that need improvement.
